# Resources

Use these official guides alongside the labs. They are optional references;
assignment requirements and submission instructions are on the assignment pages.

(content:references:w1)=
## Getting started

- [Google Cloud Console](https://console.cloud.google.com/): manage your course project, billing, and virtual machines.
- [Create and start a VM](https://cloud.google.com/compute/docs/instances/create-start-instance): refer to this when the console layout differs from the lab instructions.
- [Run an Apache web server](https://cloud.google.com/compute/docs/tutorials/basic-webserver-apache): review the VM, web server, and HTTP firewall workflow used in Assignment 1.

## Costs and account management

- [Google Cloud Free Tier](https://cloud.google.com/free/docs/free-cloud-features): check eligible services and usage limits before creating resources.
- [Budgets and alerts](https://cloud.google.com/billing/docs/how-to/budgets): learn how to monitor spending. A budget sends alerts; it does not automatically cap spending.
- [Network pricing](https://cloud.google.com/vpc/network-pricing): check external IP and network charges, which can apply separately from VM usage.

## Tools and access

- [Using Cloud Shell](https://cloud.google.com/shell/docs/using-cloud-shell): explore the browser-based terminal for managing Google Cloud. It is separate from an SSH session on your VM.
- [Identity and Access Management overview](https://cloud.google.com/iam/docs/overview): understand principals, roles, and permissions before granting project access.
