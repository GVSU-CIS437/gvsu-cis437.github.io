### Notes

You may need to install Node.js, npm, or npx. If needed, follow the instructions here:

[https://nodejs.org/en/download/package-manager](https://nodejs.org/en/download/package-manager)

Select:

- **Linux**
- **nvm**

Then follow the provided installation commands.

Before deploying, make sure:

1. You are logged into Google Cloud:

   ```bash
   gcloud auth list
   ```

2. Your Cloud Shell session is using the correct project:

   ```bash
   gcloud config get-value project
   ```

   If needed:

   ```bash
   gcloud config set project YOUR_PROJECT_ID
   ```

3. If you encounter deployment problems, check the Cloud Run logs.

4. To avoid unnecessary charges, delete Cloud Run services that you no longer need after completing the assignment.
